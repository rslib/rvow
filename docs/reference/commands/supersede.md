# rvow supersede

Replace a backlog or active change with another open change

## Usage

```sh
rvow supersede [OPTIONS] --by <BY> --reason <REASON> <OLD>
```

## Arguments

| Argument | Description |
| --- | --- |
| `<OLD>` | The change that is replaced |

## Options

| Option | Description |
| --- | --- |
| `--by` `<BY>` | The open change that replaces it |
| `--reason` `<REASON>` | Why the change is replaced |
