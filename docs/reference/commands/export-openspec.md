# rvow export openspec

Write an OpenSpec tree under &lt;dir&gt;/openspec; never overwrites

## Usage

```sh
rvow export openspec [OPTIONS]
```

## Options

| Option | Description |
| --- | --- |
| `--to` `<TO>` | The target folder; default: ./openspec-export |
| `--dry-run` | Print what would be written and write nothing |
