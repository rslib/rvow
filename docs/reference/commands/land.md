# rvow land

Land the proved task branches of a change onto its branch

## Usage

```sh
rvow land [OPTIONS] <TARGET>
```

## Arguments

| Argument | Description |
| --- | --- |
| `<TARGET>` | The change id, or a task id to land only that task |

## Options

| Option | Description |
| --- | --- |
| `--merge` | Land each task as one merge commit instead of its commits one by one |
