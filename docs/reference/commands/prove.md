# rvow prove

Run a task's stored verify command and record the proof

## Usage

```sh
rvow prove [OPTIONS] <TASK|--stale>
```

## Arguments

| Argument | Description |
| --- | --- |
| `<TASK>` | The task id or a unique prefix of it |

## Options

| Option | Description |
| --- | --- |
| `--stale` | Prove every stale task on this branch |
