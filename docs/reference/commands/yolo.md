# rvow yolo

Relax the hooks for a while: audit, auto or bypass. Without a tier it shows what is on

## Usage

```sh
rvow yolo [OPTIONS] [TIER]
```

## Arguments

| Argument | Description |
| --- | --- |
| `<TIER>` | One of `audit`, `auto`, `bypass`, `off`. |

## Options

| Option | Description |
| --- | --- |
| `--for` `<LENGTH>` | How long it stays on, such as 30m or 2h (default 2h, at most 24h) |
