# rvow block

Record that a task cannot be finished as written

## Usage

```sh
rvow block [OPTIONS] --reason <REASON> <TASK>
```

## Arguments

| Argument | Description |
| --- | --- |
| `<TASK>` | The task id or a unique prefix of it |

## Options

| Option | Description |
| --- | --- |
| `--reason` `<REASON>` | What stops the task |
