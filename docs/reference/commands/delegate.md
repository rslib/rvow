# rvow delegate

Lease one task to a subagent and print the brief to give it

## Usage

```sh
rvow delegate [OPTIONS] <TASK>
```

## Arguments

| Argument | Description |
| --- | --- |
| `<TASK>` | The task id or a unique prefix of it |

## Options

| Option | Description |
| --- | --- |
| `--worktree` `<WORKTREE>` | Make a worktree for the task, or record the one at this path |
