# rvow show

Print one requirement, task or change in full

## Usage

```sh
rvow show [OPTIONS] <ID> [PART]
```

## Arguments

| Argument | Description |
| --- | --- |
| `<ID>` | A REQ, TSK or CHG id or a unique prefix of it |
| `<PART>` | One part of a change: `proposal`, `tasks`, `design` or `spec:<name>` |

## Options

| Option | Description |
| --- | --- |
| `--full` | Print long text and task titles in full |
