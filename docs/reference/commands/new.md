# rvow new

Create a change in backlog/

## Usage

```sh
rvow new [OPTIONS] <TITLE>...
```

## Arguments

| Argument | Description |
| --- | --- |
| `<TITLE>` | The change title |

## Options

| Option | Description |
| --- | --- |
| `--spec` | Add spec deltas; without it the change is small: proposal and tasks |
