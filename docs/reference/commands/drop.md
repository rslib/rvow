# rvow drop

Give up a backlog or active change; the specs stay as they are

## Usage

```sh
rvow drop [OPTIONS] --reason <REASON> <CHANGE>
```

## Arguments

| Argument | Description |
| --- | --- |
| `<CHANGE>` | The change id or a unique prefix of it |

## Options

| Option | Description |
| --- | --- |
| `--reason` `<REASON>` | Why the change is dropped |
